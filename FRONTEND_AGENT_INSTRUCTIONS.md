# Instructions for Codex/Antigravity frontend work

Read repository `AGENTS.md` first. Then this workspace pack `README_START_HERE.md`, `design.md`, and the generated backend OpenAPI. The local app backend has **offline readiness only**.

Act as an experienced product designer, frontend engineer and API/security integrator. Prioritize an unusually polished but truthful AI safety console that records strong 1080p. No boilerplate dashboard, generic AI chat shell, fabricated charts or dummy active controls.

Before writing code, inspect actual source, decide where frontend lives and propose a 6–10 line implementation plan. Implement in short buildable increments. Use installed design skills for visual critique, not for overriding contracts. Browser interactions must call actual typed operations (or explicitly marked separate synthetic preview mode). Run build/typecheck/tests, inspect screenshots, fix responsive overflow and errors. Never disable CSRF/Origin checks or expose backend bearer credentials. Do not change protected backend code without explicit approval.

After each increment report: files changed, supported user flow, commands/tests run, screenshots reviewed, bugs, risk, remaining work. Keep a truthful demo submission checklist updated.
